
# KEENKEEPER 🌱

KEENKEEPER is a practice project built to learn the fundamentals of **Next.js** by creating a simple friendship tracker.

🔗 **Live Demo:** [KEENKEEPER](https://keen-keeper-qy17.vercel.app/)

## ✨ Features

- Browse friend profiles
- Track relationship goals and contact status
- Filter interactions by type on the timeline
- View friendship analytics with charts
- Responsive user interface

## 🛠️ Tech Stack

- Next.js
- React
- Tailwind CSS
- DaisyUI
- Recharts
- React Icons

## 🚀 Getting Started

Clone the repository and install dependencies:

```bash
git clone <your-repository-url>
cd keen-keeper
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎯 Purpose

This project was created for practice and learning, focusing on Next.js routing, components, layouts, state management, and UI development.
